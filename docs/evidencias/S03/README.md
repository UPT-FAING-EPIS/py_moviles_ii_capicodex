# Evidencias del Taller 03

Esta carpeta reúne las evidencias que no pueden demostrarse únicamente con los documentos versionados.

## Evidencias que debe producir el equipo

- `tablero-wip.png`: tablero completo con nombres de columnas, límites WIP y al menos una historia en progreso.
- `planning-poker.png`: captura de la sesión de estimación, sin exponer datos privados.
- `sprint-01-inicio.md`: enlaces verificables de la historia del Sprint 1, su responsable y su rama vinculada.
- `pr-taller-03.png`: Pull Request de la rama del taller hacia `develop` con CI en verde.
- `salidas/priorizacion_backlog.txt`: salida reproducible del script de priorización.

Las capturas complementan la evidencia, pero el informe debe enlazar primero el archivo, issue, tablero o Pull Request verificable en GitHub.
